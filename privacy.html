Privacy Policy

Last updated: 25 October 2026

Purpose

NK Math Studio GATE Publisher is a private tool for managing mathematics teaching materials.

Google Drive Access

The application requests Google Drive access to locate designated folders and upload educational PDF documents.

Data Use and Storage

Google Drive data is used for the educational publishing workflow. OAuth credentials are stored securely using GitHub Actions secrets.

Data Sharing

The application does not sell Google user data or use it for advertising. Google Drive files are not intentionally made public by this workflow.

Revoking Access

Access can be revoked in Google Account settings under third-party app connections.
